Aim:
     To develop a Python application that accepts student marks, calculates total marks, percentage and
    grade, and displays the academic performance using variables, operators, expressions, and input/output
    operations.
    
Algorithm:
         1. Start the program.
         2. Read the student's name and marks for the required subjects.
         3. Calculate the total marks using arithmetic addition.
         4. Calculate percentage using the total marks and maximum marks.
         5. Determine the grade based on the percentage using conditional expressions.
         6. Display the total, percentage, grade, and performance status.
         7. Stop the program.

Result:
       Thus, the Python application for calculating student marks, percentage, grade, and academic
       performance was implemented and executed successfully.
